# Contributing

This repository is published from releases of the Synauson examples. Each commit on
`main` is one release, tagged with the jsyn version the examples use (`v1.6.0` for jsyn
1.6.0) and listed under Releases with its notes from [CHANGELOG.md](CHANGELOG.md). The
examples are developed elsewhere, so this repository doesn't take pull requests.

To report a problem or ask a question, see [SUPPORT.md](SUPPORT.md). To report a
security problem, see [SECURITY.md](SECURITY.md).
